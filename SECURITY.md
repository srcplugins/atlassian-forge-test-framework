# Security

## Reporting a vulnerability

Report security problems privately, never in a public issue:

- **GitHub:** choose **Report a vulnerability** on this repository's **Security** tab.
- **Email:** support@srcplugins.com.

Say which version or tag you use, what you found and how to reproduce it. Never send passwords, API tokens, session files or customer data.

## Supported versions

Fixes are released as a new tag. Only the latest tag is supported.

## Contributions

Bug reports and feature requests are welcome as issues. Pull requests aren't accepted.
