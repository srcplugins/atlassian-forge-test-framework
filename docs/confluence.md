# Confluence foundation

Import the opt-in helpers from `@srcplugins/atlassian-forge-test-framework/confluence`. A Confluence app's `forge-test.mjs` exports `product = 'confluence'`; then `doctor`, `prepare` and `install` act on Confluence. `cleanup`, `preflight` and the Jira fixtures stay Jira-specific.

- `client(request, host)` reads only explicit `/wiki/api/v2/` or `/wiki/rest/api/` paths, through an authenticated Playwright request context supplied by the caller. Non-2xx, malformed JSON and transport failures throw redacted errors; denial never becomes empty data. A read that fails on transport (a dropped or stalled connection) or with HTTP 502, 503 or 504 runs once more and logs that it did. No writes, implicit pagination or redirects.
- `confluenceTarget(host)` requires an owned site with `products: ['confluence']` explicitly recorded after independent access verification. Missing products are permitted for existing Jira configurations but confer no Confluence access. Saved browser sessions belong to the site's accounts, so Confluence uses the same sessions as Jira on that site (`forge-test login` and `renew` keep them). Journals and results are Confluence's own, under `products/confluence/sites/<host>`.
- `spacePath`, `pagePath` and `spaceSettingsPath` produce escaped Confluence navigation paths. Settings requires a space key, app UUID, environment UUID and route. These are expected URLs, not claims about observed navigation.
- `pageGuard(context, options)` uses the shared Forge skeleton/frame watcher and recognizes headingless host error alerts. It must be installed before navigation; callers must call `guard.check()` on teardown. The `test` fixture from `/confluence` installs it automatically for every journey (`expectedFlags`, `appLoadLimit` and `appIds` are its options) and checks it on teardown. `spaceSettingsPage` waits for the app to be ready (`appReady`, as in [journeys](journeys.md#app-readiness)); pass `{ ready: false }` for a page Confluence should refuse. Its selectors are proven on a real site for a UI Kit space settings page; Custom UI completion isn't yet.

## Fixtures

Configure each app's space key in `fixtures.confluenceSpaces` (slug to key, for example `{ "label-history": "LHFIX" }`).

- `confluenceCall(request, host)` makes one request on the verified site and keeps the status (`{ status, body }`): explicit `/wiki/` REST paths, GET/POST/PUT/DELETE, the site as Origin, no redirects. A write is never retried; a GET that fails on transport or answers 502, 503 or 504 runs once more.
- `prepareSpace(call, app)` (and `forge-test prepare`) creates the app's space once, with the marker description and name, journaling intent first; an unfinished earlier attempt stops it until inspected. `findSpace` only reads and verifies the marker.
- `pageAdapter(call, space, runId)` is a core FixtureRun adapter for disposable pages whose title starts with the run marker. A lost create is found by its title and never repeated; cleanup rechecks title and space, trashes and then purges. `journalFile(runId)` stores the run's journal.
- `changeLabel(call, pageId, 'add' | 'remove', name)`, `pageLabels` and `restrictPage(call, pageId, { read, update })` act as the caller's account and report `applied` or `rejected`; an uncertain write is read back (`reconciled: true`), never repeated. Labels and restrictions live on a run's pages and go with them.

Still to do for hosted support: product-aware lanes, validated live shell locators and guard behavior, and an approved smoke on the registered app. Product licensing and test-account access must be verified before the site record lists Confluence. The REST endpoint and UI contracts come from the [Confluence v2 API](https://developer.atlassian.com/cloud/confluence/rest/v2/intro/) and [space settings module](https://developer.atlassian.com/platform/forge/manifest-reference/modules/confluence-space-settings/). Offline tests prove helper behavior, not site permissions or DOM accuracy.
